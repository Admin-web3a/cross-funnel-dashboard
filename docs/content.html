1. Единицы контента

Ключ склейки — video_id из utm_content. Кластер и функция берутся из справочника, а не из метки: метка после публикации неизменна, а классификация будет меняться. Сортировка по числу лидов. Колонки «Просмотры» и «Выручка на 1000 просмотров» появятся на этапе 2, когда подключим YouTube Analytics API — сейчас знаменателя нет.

4. Как ролик раскрывается на дистанции

Строка — ролик, колонка — неделя с первого лида, ячейка — сколько лидов пришло за эту неделю. У YouTube длинный хвост: ролик собирает трафик месяцами, поэтому сравнивать свежие публикации со старыми по абсолютной выручке некорректно. Именно этот разрез Миша просил для понедельничной планёрки.
